# Personal Finance Management System

## Overview
The Personal Finance Management System is a web-based application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). It helps users track their daily income and expenses, manage their budget, and visualize their financial activities through interactive charts and graphs.

## Features
- User Registration and Login
- Add, Update and Delete Income
- Track and Manage Daily Expenses
- Categorize Expenses
- View Transaction History
- Monthly Budget Management
- Interactive Dashboard
- Visualize Income and Expenses using Charts and Graphs
- Analyze Monthly Spending Patterns

## Technology Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Data Visualization:** Chart.js / Recharts
- **Authentication:** JWT

## Installation and Setup

1. Clone the repository.
2. Install dependencies in both frontend and backend.
3. Configure MongoDB connection and environment variables.
4. Start the backend server.
5. Start the React frontend.

## Purpose
The main objective of this project is to help users monitor their financial activities, understand spending habits, and make better financial decisions through data visualization.
